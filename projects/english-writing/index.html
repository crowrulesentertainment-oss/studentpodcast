STUDENT MEDIA ACADEMY · PROJECT LIBRARY

English & Writing

Use media to strengthen composition, voice, argument, literary analysis, and revision.

Five adaptable project starters for educator-led learning. Teachers select topics, tools, timing, accommodations, and assessment criteria. Students do not submit work to this public website.

All project areasEight lesson modulesEducator toolkit

PROJECT 01

Audio Story Adaptation

Adapt a short, educator-approved story into a 2–4 minute audio script.

Student deliverable: A script with narration, dialogue, sound cues, and a short note explaining adaptation choices.

Learning evidence: Narrative structure, voice, textual evidence, revision.

Suggested format: Written plan, storyboard, classroom presentation, or school-approved media draft. A recording is never required.

PROJECT 02

Book Conversation Episode

Create a short discussion segment about a class-selected book.

Student deliverable: Episode outline, open-ended discussion questions, and a written or recorded mock segment.

Learning evidence: Comprehension, evidence-based interpretation, listening.

Suggested format: Written plan, storyboard, classroom presentation, or school-approved media draft. A recording is never required.

PROJECT 03

Persuasive Audio Essay

Make a clear argument about a classroom-approved topic using credible evidence.

Student deliverable: Thesis, claim-evidence outline, source list, and 1–3 minute presentation or storyboard.

Learning evidence: Argument, source integration, organization, speaking.

Suggested format: Written plan, storyboard, classroom presentation, or school-approved media draft. A recording is never required.

PROJECT 04

Character Interview

Write an imagined interview with a literary character grounded in the text.

Student deliverable: Interview questions and answers with citations or page references supporting the character's responses.

Learning evidence: Close reading, inference, characterization, question design.

Suggested format: Written plan, storyboard, classroom presentation, or school-approved media draft. A recording is never required.

PROJECT 05

Storytelling Techniques Comparison

Compare how two creators communicate a similar idea using different narrative techniques.

Student deliverable: Comparison chart and short analytical review with examples.

Learning evidence: Analysis, comparison, media vocabulary, written clarity.

Suggested format: Written plan, storyboard, classroom presentation, or school-approved media draft. A recording is never required.
