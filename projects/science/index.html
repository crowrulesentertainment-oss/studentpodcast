Science

Translate scientific ideas into accurate, accessible explanations supported by evidence.

Five adaptable project starters for educator-led learning. Teachers select topics, tools, timing, accommodations, and assessment criteria. Students do not submit work to this public website.

All project areasEight lesson modulesEducator toolkit

PROJECT 01

Science Concept Explainer

Explain a course concept for a younger or non-specialist audience.

Student deliverable: Concept map, vocabulary list, source notes, and short explainer script.

Learning evidence: Scientific accuracy, analogy, audience adaptation.

Suggested format: Written plan, storyboard, classroom presentation, or school-approved media draft. A recording is never required.

PROJECT 02

Myth vs. Evidence

Investigate a common science claim and explain what reliable evidence does and does not show.

Student deliverable: Claim check, source comparison, qualified conclusion, and citations.

Learning evidence: Evidence evaluation, scientific reasoning, careful language.

Suggested format: Written plan, storyboard, classroom presentation, or school-approved media draft. A recording is never required.

PROJECT 03

Local Ecosystem Profile

Describe an ecosystem using educator-approved public resources and observations that do not identify private locations.

Student deliverable: Ecosystem profile, food-web visual, source list, and narration.

Learning evidence: Systems thinking, observation, ecological vocabulary.

Suggested format: Written plan, storyboard, classroom presentation, or school-approved media draft. A recording is never required.

PROJECT 04

Scientist Interview Simulation

Prepare a role-play interview using a published scientist profile or approved classroom guest.

Student deliverable: Background research, neutral questions, and a simulated Q&A with source notes.

Learning evidence: Research, question design, science communication.

Suggested format: Written plan, storyboard, classroom presentation, or school-approved media draft. A recording is never required.

PROJECT 05

Lab Process Audio Guide

Create a clear guide explaining the steps and safety considerations of a classroom-approved lab.

Student deliverable: Procedure outline, safety checkpoints, and narration or storyboard.

Learning evidence: Procedural clarity, sequencing, lab safety communication.

Suggested format: Written plan, storyboard, classroom presentation, or school-approved media draft. A recording is never required.
