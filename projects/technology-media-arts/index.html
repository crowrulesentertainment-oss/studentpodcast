STUDENT MEDIA ACADEMY · PROJECT LIBRARY

Technology & Media Arts

Design, storyboard, produce, and document media projects with accessible and ethical workflows.

Five adaptable project starters for educator-led learning. Teachers select topics, tools, timing, accommodations, and assessment criteria. Students do not submit work to this public website.

All project areasEight lesson modulesEducator toolkit

PROJECT 01

Show Identity Kit

Design a visual identity for a fictional educational show.

Student deliverable: Title treatment, color/type rationale, audience statement, and usage guide.

Learning evidence: Visual design, consistency, audience awareness.

Suggested format: Written plan, storyboard, classroom presentation, or school-approved media draft. A recording is never required.

PROJECT 02

Storyboard a Short Video

Plan a short instructional or documentary-style video without filming identifiable people.

Student deliverable: Storyboard frames, shot descriptions, narration, and accessibility notes.

Learning evidence: Visual sequencing, planning, communication.

Suggested format: Written plan, storyboard, classroom presentation, or school-approved media draft. A recording is never required.

PROJECT 03

Soundscape Composition Plan

Build a soundscape plan using original or properly licensed sounds.

Student deliverable: Sound cue sheet, source/rights log, sequence map, and reflection.

Learning evidence: Audio design, copyright awareness, creative intent.

Suggested format: Written plan, storyboard, classroom presentation, or school-approved media draft. A recording is never required.

PROJECT 04

Instructional Video Blueprint

Design a short tutorial for a school-approved skill or concept.

Student deliverable: Learning objective, shot list, script, captions/transcript plan, and quality checklist.

Learning evidence: Instructional design, technical planning, accessibility.

Suggested format: Written plan, storyboard, classroom presentation, or school-approved media draft. A recording is never required.

PROJECT 05

Production Workflow Case Study

Document how a fictional team moves a media project from idea to delivery.

Student deliverable: Role map, milestone schedule, file naming plan, review checklist, and retrospective.

Learning evidence: Workflow design, collaboration, project management.

Suggested format: Written plan, storyboard, classroom presentation, or school-approved media draft. A recording is never required.
